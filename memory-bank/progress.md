## Evolution of Project Decisions

### Decision 1: Inspired by Part Time Larry & Alpaca Focus
**Date**: 2025-12-06
**Context**: User wanted to build trading app using frameworks from Part Time Larry
**Decision**: Adopted his proven tech stack with Alpaca API (not IBKR)
**Rationale**: 
- 196 videos provide comprehensive learning resource (20+ on Alpaca)
- Alpaca simpler to start than IBKR (no TWS install)
- Commission-free trading
- Instant paper trading access
- Better for beginners
- Proven patterns reduce risk

### Decision 2: Memory Bank + .masterplan.md Approach
**Date**: 2025-12-06
**Context**: Need to track complex project with multiple phases
**Decision**: Use Memory Bank methodology + master plan document
**Rationale**:
- Memory Bank provides context continuity
- .masterplan.md gives detailed roadmap
- GitHub integration for collaboration
- Scalable to project complexity

### Decision 3: Self-Hosted AI with Ollama
**Date**: 2025-12-06
**Context**: Need AI for market research and analysis
**Decision**: Use local Ollama instead of cloud APIs
**Rationale**:
- Already have infrastructure (48GB MacBook Pro)
- Complete privacy for trading strategies
- No recurring API costs
- Llama 3.1 70B provides excellent quality
- No external dependencies for sensitive data

### Decision 4: Paper Trading First
**Date**: 2025-12-06
**Context**: Need to choose trading mode
**Decision**: Start with IBKR paper trading account
**Rationale**:
- Zero financial risk during development
- Learn platform without consequences
- Test strategies thoroughly
- Validate execution logic
- Build confidence before real money

### Decision 5: Incremental Phase-Based Development
**Date**: 2025-12-06
**Context**: Large project scope could be overwhelming
**Decision**: Break into 6 clear phases (0-5)
**Rationale**:
- Achievable milestones maintain motivation
- Each phase delivers working functionality
- Easy to collaborate with clear boundaries
- Allows for learning and iteration
- Can adjust later phases based on early learnings
